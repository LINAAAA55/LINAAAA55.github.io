# Mobile Projects Portfolio

A responsive, single-page portfolio website for showcasing Android applications. Built with plain HTML, CSS and JavaScript — no build tools or paid hosting required.

## Included projects
- **LUMA** — sleep planning, sleep-cycle calculator, alarms and sleep insights.
- **MiniShop Manager** — product catalog, search and filters, persistent cart, sales history, dark mode and French/Arabic support.

The phone visuals are **illustrative interface recreations** based on the supplied Android layouts and project descriptions. They are not screenshots captured from running devices.

## Publish with GitHub Pages
1. Create a GitHub repository named `LINAAAA55.github.io` (or use an existing repository for the site).
2. Upload the contents of this folder to the repository root. Make sure `index.html`, `style.css` and `script.js` are at the root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. The address will be `https://LINAAAA55.github.io/`.

## Before publishing
- Replace the LinkedIn placeholder with your actual profile URL.
- Add your preferred email address to the `mailto:` link in `index.html`.
- Add the direct MiniShop Manager repository URL once confirmed.
- If you have real app screenshots, replace the CSS mockup previews with those images for an even more authentic portfolio.

## Customize
Edit `index.html` for text and links. Edit `style.css` for colors, spacing and layout. No framework or package installation is needed.
